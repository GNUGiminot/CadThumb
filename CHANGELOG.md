# Changelog

## 1.0.3 — 2026-09-29

* Обновление автоматически убирает дубли установки для пользователя и для всех, оставляя одну установку для всех пользователей.
* Перед заменой файлов установщик предлагает закрыть приложения, использующие CadThumb, через Windows Restart Manager.
* Фоновый сервис новой версии запускается после завершения обновления и восстановления Проводника.

## 1.0.2 — 2026-09-29

* Старые версии удаляются после обновления; удаление занятых файлов автоматически планируется на перезагрузку Windows или следующий вход пользователя.
* Установщик распознаёт существующую установку и обновляет её в той же области (для пользователя или для всех), не создавая вторую запись программы.
* При обновлении сохраняются параметры STL, контекстного меню и автозапуска; при ошибке регистрации восстанавливается предыдущая версия.
* Обновлён интерфейс установщика и сценарий удаления. Для новых установок эскизы STL включены по умолчанию.
* Публикация релиза требует настроенной цифровой подписи и прерывается, если её нет.

## 1.0.1 — 2026-09-29

* Исправлены зависание ответов фонового сервиса, ошибки кэша и обработка повреждённых файлов.
* Исправлен рендер 3MF с разными единицами измерения, зеркальными преобразованиями и некорректной геометрией; расширена поддержка STL.
* Добавлена поддержка `.p21`, улучшены установка и удаление, а также интерфейс просмотрщика на узких экранах.
* Добавлены автоматические тесты форматов и протокола сервиса, проверка сборки Linux в CI.

## 1.0.0 — 2026-09-27

Первый публичный выпуск.

* Эскизы `.step` / `.stp` / `.3mf` (и по желанию `.stl`) в Проводнике Windows 10/11.
* 3MF: берётся эскиз, сохранённый слайсером (PrusaSlicer, Bambu Studio, OrcaSlicer, QIDI Studio); если его нет — модель рендерится (сборки, компоненты, цвета).
* STEP: OpenCASCADE, цвета деталей и сборок, автоопределение вертикальной оси (SolidWorks/Inventor/Creo — Y).
* Фоновый сервис в трее: очередь, отдельный процесс на каждую модель (лимит памяти, таймаут), дорендер тяжёлых файлов в фоне, собственный кэш эскизов, подготовка эскизов для целой папки.
* 3D-просмотрщик: вращение, сдвиг, масштаб, стандартные виды, рёбра, габариты, линейка с привязкой к вершинам, объём и оценка веса PLA, копирование картинки в буфер обмена.
* Однофайловый установщик: для пользователя или для всех, тихая установка, запись в «Установленных приложениях», перезапуск Проводника в конце.
